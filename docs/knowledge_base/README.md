# Knowledge base

This folder exists so domain knowledge and project ideas that come up in
conversation don't get lost once the conversation ends. Two kinds of
document live here:

- **`mercenaries-mechanics.md`** — facts about how Resident Evil 5/6 "The
  Mercenaries" actually works, from the author's own competitive
  experience (top 5 world solo ranking, two standing Chris STARS world
  records). Treat this as ground truth about the game, not something to
  re-derive or second-guess later.
- **`project-ideas.md`** — ideas for this project that are worth
  remembering but aren't part of the current spec/plan. Not a backlog
  with priorities or estimates, just a net to catch good ideas until
  they're ready to be scoped for real.

Both files are living documents — append to them as new mechanics or
ideas come up, rather than starting new files per conversation.
